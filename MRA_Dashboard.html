How to use the MRA Shop Floor dashboard

Everything here builds itself from the Excel workbook — you never edit the dashboard by hand.

① The two tabs up top

FLOOR = what's happening in the shop right now: bay status, the next 2 weeks, Sal's tasks, flagged jobs, pipeline and staff on leave. PROJECTS = the long-term programs (months out) with milestone gates, % complete, PM load and team capacity.

② ✏️ Edit Schedule button

The ✏️ Edit Schedule button (top of the header) opens the source workbook in Excel so you can make changes. Edit the Input tab for shop-floor jobs, or the Project Tasks tab for projects — then save (see ⑧).

③ Bay Status — see a trailer's tasks

On the Bay Status board, click a "N tasks ▸" button to drop down that trailer's open task list. Click "+N more in this bay" to reveal other jobs parked in that bay.

④ 🔧 Sal — Open Tasks by Trailer

This panel pulls every open "Sal" task out and groups it by trailer, so his queue lives in one place.

⑤ 👥 Team Capacity (Projects tab)

Groups every open Project Task by the person it's assigned to, most-loaded first, with a due-date chip (red = overdue, amber = due ≤ 7 days). Use the Everyone / People only toggle to hide crews & vendors and show just individuals — your choice is remembered.

⑥ ⛶ Expand — full-screen Gantts

Both Gantts have an ⛶ Expand button for a big, detailed view (Esc or ✕ to close):

Projects: switch detail with 1 · Projects / 2 · + Milestones, or click a project name (▾) to expand just that one to its milestone gates. Click any bar for a detail popover (PM, %, dates, and the full milestone-gate list). Zoom with 1 / 3 / 6 mo / All.

Floor: the Inside spots used (of 6) strip shows weekly use of Bays 3–5 (green → amber when full → red if over). Two trailers booked in the same inside spot get red-ringed ⚠ conflict bars with a warning up top. Click a bar for details; zoom with 2 / 4 / 8 wk.

⑦ Colors & Gantt markers

● Active   ● Scheduled   ● On hold / open   ● Past due. On the Gantts: amber ◆ = milestone gate, solid fill = % complete, a faded bar = completed, the blue band = this week, and the red line = today.

⑧ How it stays live

Edit the workbook (Input = shop floor, Project Tasks = projects) and save. The board pushes itself up every 15 minutes during the day — or run Refresh Now / dashboard.bat for an instant update. The page re-checks for new data every 30 seconds on its own. Never edit the dashboard or data.js by hand — only the workbook.
