How to use the MRA Shop Floor dashboard

Everything here builds itself from the Excel workbook — you never edit the dashboard.

① Two views — the tabs up top

FLOOR = what's happening in the shop right now: bay status, the next 2 weeks, and Sal's task list. PROJECTS = the long-term programs (months out) with milestone gates and % complete.

② See a trailer's tasks

On the Bay Status board, click a "N tasks ▸" button to drop down that trailer's open task list. Click "+N more in this bay" to reveal the other jobs parked in that bay.

③ Color coding

● Active   ● Scheduled   ● On hold / open   ● Past due. The red vertical line on the Gantts marks today.

④ Sal's tasks

The 🔧 Sal — Open Tasks by Trailer panel pulls out every open "Sal" task and groups it by trailer, so his queue is in one place.

⑤ Project Gantt — zoom & milestones

On the Projects tab, use 1 mo / 3 mo / 6 mo / All to zoom the timeline. Amber ◆ diamonds are milestone gates; the solid fill on each bar is % complete.

⑥ Team capacity

The 👥 Team Capacity panel (Projects tab) groups every open Project Task by the person it's assigned to, sorted with the most-loaded people first. Each task shows a due-date chip (red = overdue, amber = due within 7 days) so you can read everyone's workload at a glance.

⑦ It's always live

The board refreshes itself about once a minute. To change anything, edit the workbook in Excel — the Input tab for shop-floor jobs, or the Project Tasks tab for long-term projects. Save, and the dashboard updates on its own.
