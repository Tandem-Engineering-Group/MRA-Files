👥 Standardize Assignees

Merge variant spellings into ONE canonical name across all project tasks and shop-floor tasks — writes back to the workbook (board updates within ~15 min). Names that look like typos or aren't on the approved list are flagged ⚠.

👥 Manage Logins

Add a person, change someone's code, or remove a login. Codes are stored hashed — for security they're never shown, so to change one you just set a new code. Saves to the workbook (applies within ~15 min). Admin only. Real per-person sign-in + roles come in a later step.

📋 How to add or update a project

Download → fill → load it back. No Excel skills needed — it shows on the board within ~15 minutes.
  1. ⬇ Download Intake Template and open it in Excel.
  2. Fill it in: type the Project and PM once in the boxes at the top — they auto-fill down every row. Add one row per task. The gold Milestone rows are ready gates: rename/date the ones you need and delete the rest.
  3. Load it back — pick any one:
    • ⬆ Upload Filled Template (right here) — choose the file, check the preview, hit Send to schedule.
    • Drop it in the shared Intake Inbox folder.
    • Or copy your task rows → Paste → Values into the master Project Tasks sheet (columns line up 1:1).
  4. Replace vs. add: name the project exactly the same as an existing one and the upload replaces that project (a clean merge); a new name adds a new project.
  5. That's it — give it ~15 minutes to appear for everyone.
