📋 Changelog

v6.9 — August 2026

  • Added to the MRA Dashboard (☰ Menu → ✂️ Cut Optimizer) and restyled to match the MRA dark theme (same design system as Time Tracking, the Product Catalogue, and the Starlink Pricing Calculator).
  • Fixed a real bug in 2D Excel import: importing a 2D Sheet Cut workbook (the "Sheets" + "Parts" tabs from the Excel Template button) always failed with "Workbook does not contain Linear Materials and Linear Cuts worksheets" — the import code only ever recognized the Linear workbook format and had no path at all for the 2D format, even though the 2D template/export/optimizer all worked fine. Import now detects which kind of workbook was uploaded (2D: "Sheets"+"Parts", or Linear: "Linear Materials"+"Linear Cuts") and loads the right tables + settings + mode either way.

v6.8 — brought over from the original build

  • 2D rectangular sheet-cutting optimizer (factory-edge or maximum-density placement) and linear/1D cut optimizer, Excel import/export (XLSX with a colored cut diagram per sheet/piece), and a printable PDF fabrication plan.
