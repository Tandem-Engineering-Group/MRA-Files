🧭 Next Steps — Logistics roadmap

A phased path from today's scattered calendars/microsites to one connected MRA platform. Each phase delivers value on its own.
Phase 1 · now (this prototype)

One source of truth + the Master schedule

  • All tours, assets, AEs, directors, drivers, return dates & maintenance in one place — sliceable by AE / driver / director / business, calendar or list, zoom & scroll.
  • Backfill view for the supervisor with an open-gap finder + a driver calendar; arriving-at-MRA + maintenance flags.
Phase 2 · close the gaps

Retire the microsites & automate the busywork

  • Run-of-show generator → auto-built, emailed to the driver; replaces MyMobileTour + the 3 Siemens & Hyperfine microsites.
  • Driver logs from the phone — daily location, drive hours, generator hours.
  • Affiliation Report (timesheet) auto-fills from the driver logs (no more weekly manual entry).
Phase 3 · connect the platform

Tie logistics into the MRA shop + fleet you already run

  • Returns → shop work orders: a trailer hitting “back at MRA” drops its open issues onto the shop board.
  • Live trailer map (Samsara GPS, already integrated).
  • Notifications — assignment changes email / Teams / Planner the driver + AE.
Phase 4 · sign-in & roles

Right view for the right person

  • AEs see only their tours; Vicki sees all; the owner sees the Overview KPIs.
  • Move the data off scattered files into SharePoint Lists so concurrency & access are handled by the platform.
